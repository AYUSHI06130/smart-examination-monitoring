# Agile Project Plan

## Project Title

Development of Smart Examination Monitoring Platform with Integrity Analysis & Reporting System

---

## 1. Project Overview

The Smart Examination Monitoring Platform with Integrity Analysis & Reporting System is an online examination monitoring system designed to monitor candidate activities during online examinations.

The system identifies potentially suspicious activities such as face absence, multiple faces, browser focus loss, and tab switching. Suspicious events can be recorded and relevant evidence screenshots can be captured and stored.

The collected information is used for integrity analysis and generation of examination session reports.

---

## 2. Problem Statement

Online examinations can be affected by various forms of unfair practices and unauthorized activities. Manual monitoring of every candidate is difficult, especially when a large number of candidates participate in an examination.

The proposed system provides automated monitoring and event recording to assist administrators in identifying suspicious examination activities.

---

## 3. Project Objectives

The main objectives of the project are:

- To monitor candidates during online examinations.
- To detect the presence or absence of a candidate's face.
- To detect multiple faces during an examination.
- To detect browser focus loss.
- To detect tab switching.
- To record suspicious events.
- To capture screenshots as evidence for relevant suspicious events.
- To store evidence information in the database.
- To calculate an examination integrity score.
- To provide examination session reports.
- To assist administrators in reviewing examination integrity.

---

## 4. Main Features

### Candidate Features

- Candidate access to examination.
- Online examination interface.
- Camera-based monitoring.
- Examination session management.

### Monitoring Features

- Face detection.
- Face absence detection.
- Multiple-face detection.
- Browser focus monitoring.
- Tab-switch detection.

### Evidence Features

- Automatic screenshot capture.
- Candidate-specific evidence folders.
- Timestamp-based filenames.
- Screenshot path storage.
- Event and evidence association.

### Integrity Analysis

- Suspicious event tracking.
- Event count analysis.
- Integrity score calculation.

### Reporting

- Candidate information.
- Session information.
- Integrity score.
- Event summary.
- Evidence references.
- Examination session report.

## 6. Development Methodology

The project follows the Agile software development methodology.

The project is divided into smaller development cycles called sprints. Each sprint has a specific goal and set of tasks.

After development, features are tested and issues are identified and resolved.

## 7. Sprint Plan

| Sprint | Objective |
|---|---|

| Sprint 2 | Examination monitoring and suspicious activity detection |
| Sprint 3 | Evidence, integrity analysis, reporting and final testing |

## 8. Expected Outcome

The expected outcome is a functional smart examination monitoring platform capable of monitoring examination sessions, detecting suspicious activities, recording events, capturing evidence, performing integrity analysis, and generating examination reports.
