## User Stories

### US01 – Candidate Monitoring

As an administrator, I want candidates to be monitored during an examination so that suspicious activities can be identified.

### US02 – Face Absence Detection

As an administrator, I want the system to detect when a candidate's face is absent so that the event can be recorded.

### US03 – Multiple Face Detection

As an administrator, I want the system to detect multiple faces so that the presence of another person can be identified.

### US04 – Browser Monitoring

As an administrator, I want browser focus loss and tab switching to be detected so that suspicious browser activity can be recorded.

### US05 – Evidence Capture

As an administrator, I want screenshots to be captured for relevant suspicious events so that supporting evidence is available.

### US06 – Integrity Analysis

As an administrator, I want an integrity score so that I can evaluate the overall integrity of an examination session.

### US07 – Examination Report

As an administrator, I want an examination report so that I can review candidate information, events, evidence, and integrity analysis.
