## Team Collaboration

The project was developed collaboratively using a common GitHub repository.

The work was divided among the four team members based on their assigned responsibilities. Each member contributed to the development and integration of the Smart Examination Monitoring Platform.

The completed components were integrated into the common repository and tested as part of the overall system.

## Version Control

Git and GitHub were used throughout the development process for:

- Tracking changes
- Maintaining project versions
- Integrating team contributions
