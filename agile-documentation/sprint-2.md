# Sprint 2 – Examination Monitoring and Event Detection

## Project Title

Development of Smart Examination Monitoring Platform with Integrity Analysis & Reporting System

---

## Sprint Goal

To implement examination monitoring and suspicious activity detection features.

---

## Planned Tasks

- Implement face detection.
- Implement face absence detection.
- Implement multiple-face detection.
- Implement browser focus monitoring.
- Implement tab-switch detection.
- Implement suspicious event logging.
- Connect events with examination sessions.

## Work Completed

The examination monitoring functionality was integrated into the platform.

OpenCV-based face monitoring was implemented for candidate monitoring.

The system was developed to detect face absence and multiple-face situations.

Browser monitoring was implemented to detect focus loss and tab switching.

Suspicious activities were recorded as examination events and associated with the appropriate examination session.

---

## Challenges

- Face detection can be affected by lighting and camera conditions.
- Monitoring events must be associated with the correct session.
- Browser activity detection requires testing of different candidate actions.

---

## Solutions

- Tested face detection under different conditions.
- Connected events with the active examination session.
- Added event logging for suspicious activities.
- Performed functional testing of browser events.

---

## Sprint Result

The main examination monitoring and suspicious activity detection features were successfully implemented.
